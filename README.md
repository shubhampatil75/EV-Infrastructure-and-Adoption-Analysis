# EV Charging Infrastructure vs. EV Adoption Equity Analysis | Power BI

## 📌 Project Overview

This project explores the relationship between Electric Vehicle (EV) adoption, charging infrastructure development, and equity-related analysis using Microsoft Power BI. It presents interactive dashboards covering EV adoption trends, state-level comparisons, charging hardware networks, EV laws and policies, commercial fleets, and AI-based forecasting.

The objective is to transform data into meaningful visual insights that help users explore the development of EV infrastructure and adoption patterns.

## 🎯 Project Objectives

- Analyze EV charging infrastructure and EV adoption patterns.
- Compare EV-related trends across states.
- Explore charging hardware and network development.
- Understand the role of EV laws and policies.
- Analyze commercial fleet electrification.
- Explore AI-based forecasts related to EV adoption and infrastructure.
- Present findings through interactive Power BI dashboards.
